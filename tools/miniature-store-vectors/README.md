# Independent miniature Store fixture producer

This test-only producer emits exact public data for the approved private Store2 profile. It imports Node standard Buffer/crypto and accepted public kernel golden bytes; it imports no production Rust/Java encoder or signing key. SHA256 is computed with Node standard crypto. The fixed RFC public keys in bootstrap data have no private seed here. World seed/nonces in this corpus are public test values and never create an issued authorization ticket.

Run `node tools/miniature-store-vectors/generate.cjs --check` and `node --test tools/miniature-store-vectors/profile.test.cjs`. Both JSON and TSV are exact UTF-8/LF outputs. The TSV gives category/name/length/hex/SHA256/expectation, enabling bounded zero-dependency test readers. Kernel source identity comes from its reviewed public source-bundle manifest, not a computed binary or an identity claim.

The corpus has seven 224-byte purpose transcripts, one bootstrap binding preimage, four Store2 envelopes, seventeen malformed envelope records, and eleven changed/malformed auth transcripts. The 13-byte envelope header is followed by the exact compiled source pin, length-prefixed schema2 Snapshot (record type1), authority and pending presence, requests, derived hold, and outbox. Positive envelope values cover absent collections, present authority, Pending colony with exact100/40 hold, and terminal Cancelled code21 plus outbox. Bootstrap domain is exactly17 bytes, including NUL. Auth domain is15 bytes, including NUL; all five context counters and sequence are u64 little endian.

Envelope negatives focus on fixed version/source pin, overlength declarations before absent body expansion, count limits, closed presence/phase/rejection tags, request key/order/duplicates, source hash and derived hold, truncation and trailing data. Auth negatives are changed public bytes relative to a known issued-context shape; they are not decoded incoming messages and do not themselves exercise a production authorization decision. In particular a digest mismatch does not prove freshness or one-attempt consumption. Production must compare its retained private registry, trusted SQL state, real signature and live Instant independently.

The producer's three Node tests establish field offsets/widths, maximum u64 encoding, changed-context digest separation and deterministic corpus reproduction. Root independently reviewed that producer and ran it through the native verification harness. Corpus generation establishes no authorization or durable operation by itself.
