## Scope and exact primitives

Only source Store1/kernel domain7 is supported. PLAYER AND REPLICA current-policy checks, configured source owner PLAYER, exact Noise peer/ConnectionId, first-use challenge state and current SQL cuts belong to later owners. Static bytes/signatures never establish those decisions. Membership is separately admitted on both endpoints; disagreement closes, never imports roles. Prepared frontier, reservations, pending requests and outbox are inert metadata, not follower work. WorldHash means committed kernel state hash; StoreStateDigest means SHA256 exact NF-STORE-1 bytes; JournalHead means accepted SQL transition chain. These identities differ.

Every number below is unsigned LE unless explicitly stated. The outer length is u32BE, followed by exactly that many bytes and stream EOF; extra/truncated bytes refuse. Length includes header and body, excludes the four-byte prefix. No compression, strings, unknown extensions, alternate version, omitted fixed field or implicit default is permitted.

Header is126 bytes, in order: ASCII `NF-SYNC-1` plus NUL (10), version u16=1, kind u8, actual lane u8, session16, universe16, history16, ruleset32, content32. Control lane1 uses exactly `/nearfuture/peer/sync/1`; transfer lane2 exactly `/nearfuture/peer/sync-transfer/1`. Actual namespace/owner lane selects the decoder. Only kind1 Hello has session zero16; all other headers have nonzero session. Universe/history and present account/device/correlation/export/transfer IDs are nonzero16. Hashes/nonces are fixed32, with no invented zero-hash sentinel except explicitly absent fields. Fresh CSPRNG nonces are an owner requirement, not a property proven by a static shape decoder. Ruleset must later match actual WorldSpec; content is trusted configured context, not a game-content commitment.

PeerField129 is n u8, decoded canonical PeerId n bytes, then zero padding to128 bytes; n=1..128. Reject nonzero padding, malformed multihash/identity encoding and noncanonical round-trip. It is exact binary PeerId, not a base58 string. Fixture peers use the standard identity multihash of Ed25519 protobuf public keys. Production parsing uses maintained libp2p APIs; the independent writer never claims to implement general peer admission.

Point112 is StoreRevision u64, EventSeq u64, WorldHash32, StoreStateDigest32, JournalHead32. Genesis counters/head may be zero. A present Point is data that later requires exact source/base validation; shape does not prove its hashes. A separate presence u8 is exactly0 or1; absent Point requires112 zero bytes. MembershipStamp40 is revision u64 plus canonical public MembershipState digest32. Expected stamp comes from separately admitted current local policy, never the reply itself. Same revision with different digest is a conflict, not a policy update.

DeviceProof297 is universe16/history16/account16/device16/frontier u64/PeerField129/challenge32/signature64. Its scope must equal the enclosing record scope. Primitive verification uses maintained `nf_identity::signing::device_digest` and `nf_contract::signatures::verify_digest`; the digest input is closed NF-CANON-1 domain8/type5/schema1, those first72 bytes, peer length u32LE plus unpadded peer, and challenge32. Ed25519 requires canonical nonidentity prime-subgroup public key and R plus maintained strict verification. DeviceProof.challenge is SHA256 of the exact transcript below. Its frontier equals current expected membership revision; claimed account/device/peer must match the actual current mapping and required principal. Correct signature alone is not operation authority.

Profile is u16=1. Required/available/selected capability bits are exactly u32=1 (ReadProfile1Replica), optional exactly0. Implementation32 must equal the future reviewed closed compiled decoder/replay pin, and schema32 the actual Store1 schema literal SHA256. A sender cannot select code with an arbitrary hash. This initial corpus uses an explicitly synthetic expected implementation pin: no compiled/registered pin exists yet. The producer records accepted Store1 literal provenance and derives its schema digest without importing production encoders. Source consistency is not binary attestation or authentication.
