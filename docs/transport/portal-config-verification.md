Opened-file length is checked before and after the single bounded read; symlinks/reparse/nonregular entries refuse. The operator filesystem lifecycle remains cooperative: metadata preflight is not atomic protection against a concurrent owner replacing aliases or same-length content. Config anchors require independently trusted retention; storing them beside rollbackable book/cache files is not rollback protection. Existing Vault/save containment, local-disk Store preconditions, actual identity/current SQL admission and owned finite CLI cleanup are separate required composition gates.
