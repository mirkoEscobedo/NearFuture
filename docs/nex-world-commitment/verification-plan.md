2. ## Complete field coverage

Use a rich independently constructed public synthetic Snapshot containing two factions, a relation with disposition, strength/market records, a war concern with a makePeace action/config, intervals/draws and exact admitted definitions/tags. For each currently declared field, a table-driven test either changes it to another valid admitted value and expects a different world digest, or demonstrates why the boundary rejects that field change before a world token can exist. Exhaustive encoder destructuring complements these behavior tests rather than replacing them.

Valid changes include all finite scalar bit patterns and booleans, optional presence/value, selected and unselected instance IDs, full Definition identity where admitted, origin/config/source/runtime values, all current metadata IDs, raw/adjusted weariness, enemy/filter flag, config flags/chance/cooldown/repetition, action status/ended/meetings, modifier kinds/values/order, targets/market references, timer values/ordinal-linked draw records and every independently populated list. Signed-zero changes must change the commitment even if evaluator outputs compare equal. New collection entries count as field changes even when no evaluator reads them.

Reordering an ordered sequence with at least two admitted elements changes the world digest; reordered unique traits keep the same digest. Duplicate traits or duplicate keyed records, invalid references, unknown definition/module combinations, malformed text, incomplete extension inventories or nonempty uncharacterized extension identities fail boundary admission or profile validation and cannot mint a token. The four nonzero provenance digests, fixed source pin and nonzero runtime session remain mandatory. Do not bypass admission to manufacture a whole-world result for a rejected extension inventory.

Use separate realistic fixtures for branches whose admitted predicates differ. Do not falsely claim a valid mutation for source_commit or other definition/module selectors that current admission fixes. Profile documents still encode every field, including admitted constants and empty extension lists.
