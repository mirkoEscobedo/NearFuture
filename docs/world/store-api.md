# MiniatureStore owner API

Import `nf_store::miniature::*`. The owner holds one SQLite connection and private runtime authorization state. Ordinary create/open, snapshots, backup bytes, retained queries and decoded kernel records grant no active authority. Private keys remain in the configured owner's PrivateVault; SQLite receives only validated public membership and signatures. Accepted profile1 `Store` is unchanged and rejects profile2.

Create with `MiniatureStore::create(path,MiniatureGenesisSpec,membership_bytes,BootstrapPolicy,&mut impl BootstrapSigner)`. The explicit policy pins scope, public membership digest, owner account/device/keys/peer and all three controllers. Create derives genuine generated genesis, issues its own Bootstrap challenge and verifies the matching real private signer before initialization. It never creates roles, imports economic state or preclaims authority.

Open with `open_existing(path,MiniatureKnownFrontiers,AuthConfig)`. The caller retains public event/store/member/authority minima outside the replaceable database. Every open starts paused; `world()`, `snapshot()`, `snapshot_bytes()`, `known_frontiers()`, `authority()` and `pending()` expose retained data. `current_identity(account,device)` obtains the actual current nonrevoked public identity for a configured private signer; it supplies no CLI peer fallback. `backup_to(new_path)` copies only durable public state and returns the same current minima, without copying tickets or activity.

`issue_challenge(ChallengeRequest)` returns an opaque ticket, an unsigned DeviceProof template and a read-only224-byte preimage. ChallengeRequest is closed: Claim/Activity contain the configured actor/device, Prepare borrows the exact intent, Resume references an original RequestId, Commit/Cancel derive their exact retained frontier privately. Sign the issued template using the actual matching PrivateVault device key and pass `ProofAttempt{ticket,proof}`. No caller selects production time, purpose number, nonce, context, pending digest, lease or authority certificate. Capacity is64 outstanding contexts; lifetime configuration is1..30s.

A successful `claim_authority` authenticates a controlling PLAYER+AUTHORITY_CANDIDATE, persists a greater term/fresh session and clears prior tickets/leases. `prepare(intents,attempts)` authenticates every original actor separately, derives the pure frontier and sole hold, and returns Accepted only after commit. On restart or membership change, `resume_pending(attempts)` requires fresh proofs from every original actor and re-admits their unchanged exact intents/input/hold under current authority and SQL policy. Partial admission does not rewrite Pending.

`accept_activity(attempt)` admits a real Lease-purpose proof for the actual next tick into private ephemeral state. `commit(&MiniatureBatch,owner_attempt)` accepts only the exact advancing batch, complete current Pending admission, live current-N controller activity and the exact persisted owner's fresh Commit proof. It returns DurableAck only after SQLite commit. Activity N cannot authorize N+1. The `*_with_hook` variants expose accepted fault boundaries; a hook supplies neither authorization nor a fake clock, and the final cut revalidates all production freshness/policy after BeforeCommit.

`cancel_pending(MiniatureCancelCause,owner_attempt)` authenticates the current owner against current SQL policy and the exact retained old frontier. AdmissionChanged requires an actual changed admission context/policy; Cancelled is explicit. Cancellation retains original intents/terminal outcomes, frees the hold and does not advance the world tick or spend resources. A revoked previous owner cannot raw-cancel; a valid new controlling Candidate must first claim a greater term.

`query_bound(request,account,device,scope)` returns the original immutable intent and Pending/Committed phase, after exact retained bindings match. This is a local data port: the composed owner authenticates its configured principal before lookup. Use it before rebuilding any retry intent with newer revisions. `outbox()` returns bounded copied terminal metadata; `ack_outbox(operation)` is trusted local delivery metadata guarded by a claimed runtime/current durable owner role, without a strategic effect, remote authority or tick advancement.

MembershipRepository reuses the accepted public codec/CAS frontier. A successful membership change clears runtime tickets/activity; older checked authority/Pending revisions remain valid paused recovery data. Advance requires exact fresh current equality. Full/Io/Corrupt during checked writes and failed COMMIT quarantine the owner; status must be recovered through a new verified open before retry. Callback errors or expired admission roll back and do not fabricate SQLite storage-fault evidence.
