# MiniatureStore durability checks

MiniatureStore is a separate profile2 SQLite owner. It grants no authority on create or reopen. Fresh issued Claim, all original actors' Resume proofs, current-N activity and the exact current owner's Commit proof precede an advancing transaction. Public known frontiers and backup copies contain durable data; a backup carries no runtime grant.

The author native checks use `npm.cmd exec -- workspace-template verify` on inspected private harnesses with `--scope module --module node:.`. Every spawned Cargo/test child is contained by the package's Windows Job Object. The process fixtures also own their exact child handle, deadline, kill and reap; readiness comes from actual boundary output.
