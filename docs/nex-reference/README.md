# Adapted Nex source reference checkpoint

`nex-reference` is an isolated Java17 source oracle for a bounded WarWearinessConcern lifecycle and one explicitly selected non-player peace attempt. It has no dependencies, original Nex/game JAR, Global, MarketAPI, live manager, resource spend, relationship mutation or random source. The artifact contains only nf.nex.reference classes and the complete upstream MIT notice.

Public inputs are ordinary immutable copied facts. The concern oracle preserves active exact-class suppression, threshold comparisons, ended-object behavior, abort requests and ordered inherited alignment/trait/faction priority writes. It returns existing priority entries separately from new writes. It does not guess proprietary MutableStat aggregation, overwrite/ordering behavior or an aggregate total priority. All priority comparisons in the corpus use exact raw f32 bits of individual writes.

The selected-enemy oracle adapts the relevant checkPeace guards and tryMakePeace arithmetic. It receives both weariness/event values, level/divisor config, eligibility facts and ordered supplied Java Math.random double bits. It records a requested ceasefire/treaty event followed by two weariness-modification calls. These are call requests, not applied relations or predicted post-alliance weariness. Actual event creation success, alliance propagation, live Intel/delegate state, player prompts and full offensive enumeration remain unavailable.

The three immutable source constants are matched exactly: minimum war interval30f, event peace multiplier40f, treaty chance0.3f. Mutable configuration values remain explicit inputs. Input and derived non-finite values are unavailable, not clamped or broadly approximated. The source uses a double draw compared against a float chance; adjacent f64 values therefore remain distinct. Consumed draw counts preserve conditional second-draw behavior.

[Source adaptation](source-adaptation.md) identifies pinned code and changes. [Verification](verification.md) records exact tests and residuals. [War corpus](../../java/nex-reference/src/test/resources/war-v1.tsv) and [peace corpus](../../java/nex-reference/src/test/resources/peace-v1.tsv) contain explicit raw-bit inputs/expected outputs. These are synthetic fixtures, not game captures. No source-to-installed-JAR match, total priority equivalence, real captured coherence, shadow equivalence, writer suppression or authority eligibility is certified. Whole issue #14 remains open for those gates.
