Adaptation changes are explicit: game getters become supplied values; exact-class comparison uses a closed mapped class token; localized UI/log strings are omitted; MutableStat writes become ordered data; end() records abort instead of invoking a live delegate; actual Math.random calls become purpose-checked supplied double draws; event creation and manager.modifyWarWeariness calls become immutable requested-call records. Additional finite/count/closed-tag guards reject unsupported inputs before reference execution.

The baseline concern tag/trait subset is closed. Military/disposition modifier branches, arbitrary replacement concerns/listeners, and actual HashSet/MutableStat iteration behavior are uncharacterized. The input tag order is an explicit supplied order; its agreement with loaded game ordering requires capture evidence. Existing entries are preserved separately, so stale modifier disappearance is not invented. No aggregate priority is computed.

The peace branch covers one explicitly selected non-player enemy. Inputs supply relevant eligibility predicates; this does not emulate live offensives, commissions, faction diplomacy, event success or manager state. Multi-target sorting/three-try traversal, player offers/cooldown, returned Intel success and subsequent enemy-cache updates are omitted and remain unavailable. Recorded weariness calls do not assume effects on alliance members or actual final values.
