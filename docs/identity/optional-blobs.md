# Strict optional private blobs

The additive PrivateVault::read_optional_private_blob distinguishes genuine absence from present corruption. None is returned only after a no-follow entry lookup reports OS NotFound and fresh owner-private root checks confirm an actual directory. Present invalid wrappers, nonregular/reparse entries, inaccessible files or invalid roots return an error. The accepted reader, key formats, wrapper, ACL policy and every existing caller are unchanged. This is a cooperative exclusive-lifecycle read; same-owner concurrent replacement is not an atomic filesystem snapshot.
