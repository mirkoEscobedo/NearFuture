# Identity verification checkpoint

2026-10-07, scoped implementation accepted by independent read-only R2; whole issue integration acceptance remains pending.

`cargo test -p nf-identity --locked --offline` verifies generated disposable identities only. Public policy tests cover history pinning, signed one-use grants, expiry, tampering, recipient possession, role escalation, unknown devices, member-frontier revocation, current/new-key account and device rotation, transport peer/challenge binding and explicit lost-account recovery refusal. The closed domain8 codec rejects baseline generic registration, malformed oversized counts and oversized records; a finite 10,000 input mutation/truncation run re-encodes accepted forms exactly. This is finite adversarial testing, not a proof of every possible input.

Meaningful public-seam RED/GREEN failures were observed for cross-history admission; absent recipient membership on valid one-use redemption; unknown-device authorization; non-advancing revocation frontier; unchanged account/device keys after authenticated rotation; damaged local keys being silently loaded; and missing immutable private IPC blob storage. ACL setup initially failed under Cargo because Windows PowerShell's security module was not resolved; fixed trusted explicit platform-module import made that same bounded test pass.

Windows tests independently inspect actual protected owner-only ACLs using icacls, then deliberately grant Everyone read and require private loading to refuse. They test literal paths with spaces/quotes, saved-game copying without keys, no accidental identity overwrite, missing/corrupt key refusal, immutable staging and membership-selected rotated-key reload. Helper subprocesses receive no keys, run hidden with bounded ownership and suppress output. Test directories use generated names under ignored .tmp and are removed on Drop, including panics; prior failing-test directories were explicitly removed inside the verified workspace boundary.

`cargo clippy -p nf-identity --all-targets --locked --offline -- -D warnings` passed. Exact dependency versions are nf-contract plus maintained getrandom0.4.3, zeroize1.9.0 and sha2 0.10.9; foundational Dalek strict verification is reused. Production/tests remain below package topology thresholds.

The actual nf-store public snapshot CAS integration now proves atomic consumed-invitation/grant state, restart-stable device revocation, stale CAS and rollback-frontier rejection in the Windows test described below. Linux 0700/0600/current-UID tests are authored but require an observed Linux run. Source-build Windows helper availability is verified; packaged helper distribution is not implemented. No game, network identity handler, economic operation, installed account or operational role was modified or enabled.

Independent review R1 found one owned-helper wait-error cleanup gap. A real hidden PowerShell sleeper fault regression first observed the orphan in RED, explicitly cleaned it, then passed in GREEN with an independently absent process. Full post-repair identity tests and strict lint passed during R2; no crypto mocking or secret output is used.
