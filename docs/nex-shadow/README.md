# Portable diplomatic shadow slice (partial issue #15)

`nf-nex-shadow` is a pure `no_std` source-faithful evaluator over owned values. It depends only on `nf-nex-boundary`, `nf-contract` and pinned no-default-features SHA256. It has no game, network, SQL, clock, random source, mutable world reference or actuator. Every bound output reports `ShadowOnly`; synthetic and captured-unverified provenance cannot grant authority.

The pinned Nexerelin source is v0.12.2c commit `a669f4d0740e95a4acbb6b894dde09ade67aa754`. Exact public source digests and deliberate Java substitutions are documented in [the source adaptation](../nex-reference/source-adaptation.md). The Rust crate retains the complete Nexerelin MIT notice. No installed-JAR or proprietary implementation equivalence is implied.

`evaluate_war` reproduces selected `WarWearinessConcern.generate/update/isValid` operations: exact-class active duplicate suppression, the float threshold, ended-object behavior and abort request, existing priority preservation, and ordered flat/alignment/trait/faction modifier writes. `war_from_world` copies those facts from an admitted immutable `NexWorld` and refuses missing manager/map facts, absent current instances and disabled generation. It does not invoke the lazy mutating weariness getter. The boundary fixture and core tests show the source snapshot remains unchanged.

`evaluate_selected_peace` separately accepts every explicit selected-target eligibility fact, coefficient and purpose-ordered double draw. It returns only immutable proposed event/weariness call data. Float operations retain source assignment order; no fused multiply-add or fixed-point conversion is introduced. The float chance is promoted to double for comparison, exact raw bits are compared, and no epsilon or hidden random draw is used. Conditional treaty draws and effect-call order are preserved. `selected_peace_from_world` always returns `MissingFact`: the frozen snapshot cannot supply every required predicate, counterpart weariness/disposition, rule or exact draw purpose. The current kernel's synthetic peace evaluator is not used.

The supported direct-input domain is deliberately conservative: five recognized concern tags, three recognized traits, at most 256 existing concern facts, 64 prior modifiers, finite f32 values, and at most two finite f64 draws in [0,1). Priority IDs use at most 128 UTF8 bytes, versus the Java reference's 128 UTF16 units; Unicode13/NFC admission, no controls and duplicate-state rejection can further restrict inputs. These restrictions are explicit unavailability, not silently approximated native semantics. Existing modifiers remain separate from writes. Proprietary MutableStat aggregation is never calculated.

`ShadowSession` binds the supplied source/runtime/config/reference/corpus/implementation/capture-policy identities, provider, universe/history, campaign/branch, runtime session, frontier, named subject/optional concern instance and supported copied-input digest. Acceptance requires an explicitly supplied current owner `ShadowMetadata` and current `ShadowInput`: it validates the current commitment and checks exact session/result/current binding equality. Identical numeric facts with a newer session, frontier, source, configuration, policy, subject or instance reject. This accepts copied-facts diagnostics only and never certifies a world publication.

`evaluate_world_war` verifies the admitted provenance and named target, then evaluates only the supported copied facts. Its digest omits unused boundary fields and other concern instance IDs, so it is not a whole-Snapshot commitment. Its privately constructed `WorldWithoutCommitment` result remains inspectable `ShadowOnly`; guarded acceptance always returns `MissingFact` until a reviewed complete-world commitment exists. There is no mutable public conversion from that marker to `CopiedFacts`. The direct copied-facts evaluator is a diagnostic primitive, not an alternate world-publication path.

Invalidation/disconnect/save/load policy disables diagnostic acceptance; provider errors through the owner evaluation method disable optional work. This cooperative value-only fence requires the actual owner to supply current metadata and invalidate on lifecycle changes. Native lifecycle coverage, coherent capture and aggregate revision/read-set mappings remain unavailable; aggregate IDs/revisions are never fabricated from concern instance IDs.
Diagnostics contain static mismatch classes plus source/config/input/corpus/implementation digests. A count/byte-bounded stream coalesces equal records and explicitly counts dropped optional diagnostics. It contains no raw snapshot, faction/display names, private paths, tokens or chat. The reproduction function returns bounded private identity bytes only on explicit request for caller-reviewed synthetic input; captured-unverified input rejects. Observation is a supplied evidence label, not a security classifier. There is no automatic captured-data export or persistence. The public synthetic file round-trip test demonstrates the external persistence seam without adding ambient effects to the core.

All 10 war and 16 selected-peace source corpus cases pass both exact Rust goldens and the actual Java17 differential oracle. Across worker counts 1/2/4 and eight repetitions, reordered worker completion produces identical ordered outputs for all 26 cases. These are scoped adapted-source certificates. G1 capture/writer/lifecycle coverage, native MutableStat/order, action ranking/selection, multi-enemy/player paths, real event success/alliance weariness effects and installed source/JAR equivalence remain unobserved. Issue #15 remains partial and no performance improvement is claimed.

The separate [complete admitted-snapshot profile and guard](../nex-world-commitment/proposal.md) now support diagnostic comparison through WorldShadowSession. They commit every declared Snapshot field and recompute the supplied current world plus full current owner binding before acceptance. The original world factory guard remains MissingFact; it has no scope conversion into the new result. Full-Snapshot equality does not establish actual native capture completeness or grant promotion authority.
