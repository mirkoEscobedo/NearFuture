# Action-only private diagnostic identity V2

This profile binds supplied MakePeaceAction.canUse eligibility facts to a copied-facts shadow diagnostic. It does not certify their capture, native identity, a world commitment or an economic capability. The implementation remains pinned to the existing Nex source and license attribution. An absent target is a supplied fact of no target, not unknown live state.

The closed domain is the 15 ASCII bytes NF-NEX-SHADOW-2 followed by NUL (16 bytes total), then little-endian u16 version 2. The private encoder exposes no arbitrary version selector. Metadata validation, bounds and field order are shared with V1; V1 retains its original domain, version and War/SelectedPeace kind tags and fixture bytes.

After the common metadata header, ShadowOnly authority is byte 1. In this action-only profile kind byte 1 denotes the exact MakePeaceAction.canUse override. The payload contains diplomacy-enabled, concern-can-make-peace and target-present booleans, then hostile iff present, then faction-diplomacy-disabled. Booleans are single bytes 0 or 1. This profile does not encode War or SelectedPeace input, inherited cooldowns, ranking, RNG, IO or mutation.

The independent Node standard-crypto vector is 434 bytes with SHA-256 5910e944560a7655a232d48c53ea2934da74f38ee5f6b941a5fbd007d01df738. Its header uses the pinned source commit, synthetic digest values 1 through 8, IDs 11/12/15/16/17, runtime session 13, event frontier 14, subject hegemony and no concern instance. The generator imports neither Rust nor expected business output.

The executed contracts check these bytes and digest, then evaluate supplied facts as typed eligibility with CopiedFacts and ShadowOnly without altering input. A separate current-input acceptance contract rejects stale metadata, equal-boolean fact drift, invalidation and disabled providers. Action-output comparison reports Decision only for unequal booleans and Kind across action/V1 outputs; equal values never establish equal identities or freshness. The legacy acceptance API remains V1-only. decode_action_input accepts only this closed private V2 profile, with a maximum record length of 571 bytes, source-commit text capped at 40 bytes and subject text at 128 bytes. It checks exact tags and boolean encodings, complete consumption, UTF8/Unicode13/NFC text, pinned source/runtime/digest metadata and canonical re-encoding. Decoding CapturedUnverified preserves that supplied label; replay_synthetic_action rejects it and reproduces only explicitly supplied Synthetic copied facts through ShadowSession. The result remains CopiedFacts and ShadowOnly. An actual Java-authority/Rust-worker loop and licensed live capture, save/load and disconnect validation remain separate unimplemented or unqualified delivery steps. This private profile confers no native world authority or economic capability.
