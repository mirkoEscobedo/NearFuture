# SystemPackageTopology NF-SPT-1, schema 1

Separate typed data profile. Existing NF-CANON-1 canonical registries, all existing domains, Intent Payload and corpus stay unchanged. A complete current Rust schema/mod and Java Registry/Records/RecordCodec audit establishes their local closed pairs, not globally unallocated domains. Separate named header avoids inventing domain authority. No negotiation/transport handler accepts this profile yet.

Exact fields, concatenated without padding/trailing data: ASCII NF-SPT-1 followed by NUL (9 bytes), schema u16LE=1; UniverseId16, HistoryId16, owner AccountId16, stable system EntityId16; immutable revision u64LE positive; descriptive local campaign_day_millis u64LE (raw unsigned metadata, never shared clock); publication selection tag u8=1 (explicit selected topology summaries only); dependency count u16LE0..64, rows semanticKeySHA25632 + required u8{0,1} strictly sorted unique by unsigned key; entity count u16LE1..128; rows EntityId16 strictly sorted unique, kind u8{1 Star,2 Planet,3 Station}, parent presence u8{0,1} then EntityId16 if present, dependency presence u8{0,1} then dependency ordinal u16LE if present, label presence u8{0,1} then u16LE byte count0..128 + exact canonical UTF8 bytes if present. None differs from Some(empty). All IDs/semantic keys nonzero. No generic blob, class path, URL, script, save object or executable field. Digest is SHA256 of all exact profile bytes; it authenticates no owner.

Lower-only Limits: bytes<=65536, entities<=128, dependencies<=64, labelBytes<=128. Flat header baseline96 bytes; dependency33; entity20 plus parent16 + dependencyOrdinal2 + optional label2+bytes. General shape upper bound96+64*33+128*(20+16+2+2+128)=23712 bytes <65536. Exactly one parentless Star makes the tight maximum23696 bytes (minus16); neither is a measured heap/RSS envelope. Decoder checks document size before parse, counts and minimum remaining rows before allocation, then full semantics; encode measures before output allocation. Caller-created owned values do not certify wholeprocess allocation budgets.

Exactly one Star root (no parent); Planet/Station each have one present parent in the same selected system. IDs and references denote only topology, not physical game orbital parameters. Parent indices are resolved once then iterative per-node visited walks detect cycles and bound logical chain depth128. This is a flat profile: logical orbit-chain depth128 is not NF-CANON-1 recursive record depth32 and does not increase/change that codec budget.

select(source,selectedIds,allowedSemanticKeys,limits) is an explicit public privacy boundary: source must validate; selection and key allowlist bounded/sorted/unique; every selected ID exists; parent must remain selected or reject Privacy (never pull an unselected parent); referenced key must be allowed or reject Privacy; output contains selected rows and only their referenced dependencies, ordinals remapped to sorted output dependencies. Other unselected labels/dependencies do not enter output. This function cannot certify caller consent, membership or visibility of the supplied source; those signed admission/real export interfaces remain later work.

diagnose_content(package,knownSemanticKeys,limits) returns Known or Abstract(sorted missing required keys), no playable/native mode. Unknown optional keys do not grant native assets either. Canonical structural decode does not fetch/instantiate/substitute content. No network download, durable revision/tombstone enforcement or live object construction.
